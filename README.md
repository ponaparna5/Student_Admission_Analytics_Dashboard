# Student Admission Analytics Dashboard

## Project Overview

This project is a Power BI dashboard created to analyze student admission data.

The dashboard provides information about total students, total fees, courses, age groups, and monthly admission trends.

## Tools Used

* Power BI
* Microsoft Excel

## Dashboard Features

* Total Amount
* Total Students
* Total Courses
* Sum of Fees by Course
* Students by Age Group
* Monthly Admission Trend
* Admission by Course
* Filters for City, Course, and Year

## Key Information

* Total Amount: ₹7M
* Total Students: 772
* Total Courses: 8
